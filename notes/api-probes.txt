createFolder full source:

  createFolder(tabs = [], options = {}) {
    const filteredTabs = tabs
      .filter(tab => !tab.hasAttribute("zen-essential"))
      .map(tab => {
        gBrowser.pinTab(tab);
        if (tab?.group?.hasAttribute("split-view-group")) {
          tab = tab.group;
        }
        return tab;
      });

    const workspacePinned = gZenWorkspaces.workspaceElement(
      options.workspaceId
    )?.pinnedTabsContainer;
    const pinnedContainer =
      options.workspaceId && workspacePinned
        ? workspacePinned
        : gZenWorkspaces.pinnedTabsContainer;
    const insertBefore =
      options.insertBefore ||
      pinnedContainer.querySelector(".pinned-tabs-container-separator");
    const emptyTab = gBrowser.addTab("about:blank", {
      skipAnimation: true,
      pinned: true,
      triggeringPrincipal: Services.scriptSecurityManager.getSystemPrincipal(),
      _forZenEmptyTab: true,
      createLazyBrowser: true,
    });

    gBrowser.pinTab(emptyTab);
    tabs = [emptyTab, ...filteredTabs];

    const folder = this._createFolderNode(options);

    if (options.insertAfter) {
      options.insertAfter.after(folder);
    } else {
      insertBefore.before(folder);
    }
    gZenVerticalTabsManager.animateItemOpen(folder);

    folder.addTabs(tabs);

    // Fixes bug1953801 and bug1954689
    // Ensure tab state cache update so group can be saved/closed reliably.
    folder.tabs.forEach(tab => {
      gBrowser.TabStateFlusher.flush(tab.linkedBrowser);
    });

    this.updateFolderIcon(folder, "auto");

    if (options.renameFolder) {
      folder.rename();
    }

    this.#groupInit(folder);
    return folder;
  }

createFolder options:  { workspaceId?, insertBefore?, insertAfter?, renameFolder? }
createFolder returns:  the new zen-folder element.

Notes:
- The leading about:blank "empty tab" is real, not a placeholder — it owns the folder's
  pinned state. This matches the DOM where every folder shows a first <tab zen-empty-tab="true">.
- folder.tabs is a live collection of contained tabs.
- gZenVerticalTabsManager.animateItemOpen is the entry-into-DOM animation.
- A private #groupInit(folder) is called at the end; we cannot call private methods directly.
  If we need to recreate a folder programmatically we must use createFolder, not _createFolderNode.

High-leverage hook points
-------------------------
For an "enhance folders" mod, the highest-leverage hooks are:
  - gZenFolders.updateFolderIcon         — to inject per-folder icon logic
  - gZenFolders.setFolderUserIcon        — to set custom icon explicitly
  - gZenFolders.on_TabGroupCreate        — to apply mod state to new folders
  - gZenFolders.storeDataForSessionStore — to persist mod state
  - gZenFolders.restoreDataFromSessionStore — to rehydrate mod state
  - gZenFolders.animateCollapse / animateExpand — to alter animations
  - nsZenFolder.prototype.on_click       — to alter click behavior
  - nsZenFolder.prototype.rename         — to alter rename UX

Implications for the mod
------------------------
- Selector for any folder:                zen-folder
- Selector for collapsed folder:          zen-folder[collapsed]
- Selector for folder owning active tab:  zen-folder[hasactivetab]
- Selector by stable id:                  zen-folder#<id>
- Selector scoped to workspace:           zen-folder[zen-workspace-id="<uuid>"]
- To collapse/expand programmatically:    toggle the `collapsed` attribute (no method API).
  Confirm whether on_click is the right entry point or whether attribute toggle is enough.
- To add tabs to a folder:                folder.addTabs([tab, ...])
- To create a subfolder:                  folder.createSubfolder(...)   — signature TBD
- To rename:                              folder.rename(newLabel)        — signature TBD
- To remove:                              folder.delete()                — destructive, confirm semantics
- To unpack (flatten):                    folder.unpackTabs()
- To unload contained tabs:               folder.unloadAllTabs()
- Per-folder color override:              set style="--tab-group-color: ...; --tab-group-color-invert: ...; --tab-group-color-pale: ..."
                                          (workspace-derived defaults can be replaced without touching workspace)
